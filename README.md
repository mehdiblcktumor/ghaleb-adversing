# قالب خام ADVERSING — آژانس تبلیغاتی (طراحی / اجرا / چاپ)

قالب تک‌صفحه‌ای کامل، **بدون بک‌اند و بدون دیتابیس**، با HTML5 + CSS3 + JavaScript خالص (Vanilla).
ساختار، چیدمان و متن‌ها بر اساس تصویر اولیه بازسازی شده و کل هویت برند روی **ADVERSING** منتقل شده است.

---

## ۲) اجرا

نیازی به سرور، نصب پکیج یا دیتابیس نیست:

1. `index.html` (یا `adversing-single-file.html`) را با مرورگر باز کنید، یا
2. پوشه را با هر وب‌سروری سرو کنید (مثلاً `python -m http.server`).

هیچ درخواستی به اینترنت ارسال نمی‌شود؛ فونت، آیکون و تصاویر همه محلی هستند.

## ۳) هویت برند (ADVERSING)

| مورد | مقدار |
|---|---|
| زرد برند | `#FFCB06` |
| زرد روشن (گرادیان) | `#FFE071` |
| زرد تیره (hover / خط) | `#D9A400` |
| مشکی برند | `#050A12` (پس‌زمینه) و `#0B131F` (کارت‌ها) |
| شعار | طراحی / اجرا / چاپ |
| شعار لاتین | ADVERTISING AGENCY |

**لوگو در سایت** به‌صورت SVG درون‌خطی (اسپرایت) در ابتدای `index.html` و با شناسهٔ `i-logo` قرار دارد؛
هر جای سایت با `<svg><use href="#i-logo"/></svg>` فراخوانی می‌شود. برای تغییر لوگو فقط همان
`<symbol id="i-logo">` را عوض کنید یا مستقیم محتوای `assets/brand/adversing-mark.svg` را جای آن بگذارید.

**استفاده از لوگو روی محصولات:** تصاویر `assets/` لوگوی ADVERSING را روی خود محصولات (کیسه، جعبه،
کارت ویزیت، ماگ، بروشور، بسته‌بندی) دارند تا نمونه‌کارها با برند شما هم‌خوان باشد.

## ۴) بخش‌های صفحه (به ترتیب)

1. **هدر چسبان**: نشانهٔ ADVERSING + نام برند + شعار، منوی ۶ آیتمی، جستجو، سبد خرید با نشان تعداد، ورود/ثبت‌نام، منوی همبرگری در موبایل
2. **اسلایدر هیرو**: ۳ اسلاید، تیتر دوخطی (خط دوم زرد)، خط تأکید زرد زیر تیتر، دکمهٔ زرد + دکمهٔ دورخط، فلش‌ها، نقاط، تعویض خودکار، درگ/لمس، توقف روی هاور
3. **نوار ویژگی‌ها**: ۵ ویژگی با آیکون زرد و جداکننده
4. **دسته‌بندی محصولات**: ۸ کارت تصویری
5. **محصولات جدید**: بنر بزرگ «کارت ویزیت خاص» + ۵ کارت محصول با برچسب برند، قیمت و ۵ ستاره
6. **فرایند سفارش آنلاین**: پنل تیره با تصویر ویدیو، دکمهٔ پخش و ۴ مرحلهٔ شماره‌دار
7. **بنرهای پیشنهاد**: «تا ۳۰٪ تخفیف» (عریض) و «محصولات پرطرفدار» (باریک)
8. **نظرات مشتریان**: پس‌زمینهٔ روشن، کارت‌های افقی با اسکرول
9. **فوتر**: اطلاعات تماس، دسترسی سریع، خدمات ما، خبرنامه، لوگو و شبکه‌های اجتماعی، نوار کپی‌رایت
10. **دکمهٔ شناور گفتگو**

## ۵) شخصی‌سازی سریع

### رنگ‌ها
در `css/styles.css`، بخش `:root`:

```css
:root {
  --bg: #050a12;          /* پس‌زمینه تیره */
  --gold: #ffcb06;        /* زرد برند ADVERSING */
  --gold-light: #ffdf6b;
  --gold-deep: #d9a400;
  --panel: #0b131f;
  --text: #eef3fa;
  --text-muted: #93a2b7;
  --light-bg: #f6f7f9;
  --radius: 16px;
  --container: 1360px;
}
```

### متن‌ها، قیمت‌ها، اطلاعات تماس
همه در `index.html` و بدون JSON/بک‌اند هستند. موارد برندمحور که الان ست شده‌اند:

- نام برند: `<span class="brand-name">` و `<span class="brand-tag">`
- تلفن / ایمیل / آدرس: بخش فوتر (`info@adversing.ir`، `۰۲۱-۱۲۳۴۵۶۷۸`)
- شبکه‌های اجتماعی: لینک‌های `#instagram`، `#telegram`، `#linkedin`، `#whatsapp` در فوتر (فعلاً به آدرس‌های نمونه اشاره می‌کنند — جایگزین کنید)
- کپی‌رایت: `۱۴۰۶ © کلیه حقوق برای ADVERSING محفوظ است.`
- برچسب برند روی کارت محصول: `<span class="product-brand">ADVERSING</span>`

## ۶) تغییرات رایج

| چه کاری | کجا |
|---|---|
| عوض کردن لوگو | `<symbol id="i-logo">` در ابتدای `index.html` یا فایل `assets/brand/` |
| افزودن/حذف آیتم منو | `<nav class="main-nav">` |
| افزودن کارت محصول | یک `<article class="product-card">` کپی کنید |
| افزودن اسلاید هیرو | یک `<div class="hero-slide">` کپی کنید (نقاط و فلش‌ها خودکار اضافه می‌شوند) |
| افزودن نظر مشتری | یک `<article class="testi-card">` کپی کنید |
| سرعت اسلایدر | متغیر `DURATION` در `js/main.js` (میلی‌ثانیه) |
| نشان سبد خرید | متن داخل `<span class="cart-badge">` |

## ۷) رفتارهای تعاملی (فقط نمایشی)

- اسلایدر هیرو: تعویض خودکار ۷ ثانیه‌ای، فلش، نقاط، درگ/لمس، توقف با هاور
- منوی موبایل: باز/بسته + بستن با کلیک روی لینک
- نظرات مشتریان: اسکرول افقی با فلش (RTL-aware)
- دکمهٔ علاقه‌مندی: تغییر وضعیت قلب
- منوی فعال بر اساس اسکرول (`IntersectionObserver`)
- هیچ فراخوانی سرور، سبد خرید واقعی یا پرداختی وجود ندارد؛ فرم‌ها با `onsubmit="return false;"` خنثی شده‌اند

## ۸) سازگاری و کیفیت

- ریسپانسیو بدون سرریز افقی از ۳۲۰px تا ۱۹۲۰px (تست‌شده)
- RTL کامل با `inset-inline` / `margin-inline`
- مرورگرها: Chrome / Edge / Firefox / Safari مدرن
- دسترس‌پذیری: `aria-label` روی دکمه‌های آیکونی، `aria-expanded` منو، پشتیبانی از `prefers-reduced-motion`
- بدون هیچ کتابخانه یا CDN خارجی
